## Calibration of the model
For this model, parameter combinations are selected to reproduce broad, independently reported thymic selection percentages rather than a predetermined stiffness-dependent outcome: positive selection comprising approximately 3–5% of thymocytes (Stritesky et al. 2012) and a negative:positive selection ratio of 6–9 (Sawicka et al.). This calibration approach follows phenotypic calibration (output-level inverse modelling) approach. These calibration targets are acknowledged to carry measurement uncertainty arising from proliferative expansion of DP thymocytes and variation across experimental systems. They are used here as order-of-magnitude anchors for a proof-of-concept model rather than as precisely constraining benchmarks, and the sensitivity analysis assesses model behavior across the reported uncertainty ranges of both targets. 

## Validation and Experimental Feedback
As a first-generation proof of concept, the model is not yet intended to provide quantitative predictions of thymic selection outcomes. Therefore, validation should be planned to proceed hierarchically, beginning with verification of model implementation and empirical constraint of model inputs, followed by validation of individual mechanistic components and finally experimentally testing integrated model predictions. The outputs from sensitivity analyses can be used to prioritize experiments that constrain uncertain parameters or mechanisms with the greatest influence on model behavior. The hierarchy of the experiments has been divided into three stages.

### Stage-1: Validating Model Inputs
This stage comprises of measurements of values used the model that need to be properly parameterized. The model currently uses assumed values for stromal density, stiffness field parameters, and the biphasic migration curve. Without measured values for these, even correct qualitative results could be coincidental.
The primary set of measurements in this category that exemplify the thinking behind this category would be about the stiffness of thymic stroma. The model uses S_mean, S_std, S_stiffer, and S_softer as free parameters, which are currently set phenomenologically. The model's non-monotonic stiffness-selection relationship depends critically on K_high (= 4.0 kPa), the stiffness at which migration starts declining. Whether real thymic stromal stiffness sits below, at, or above this value, can shed light on whether the model is making predictions in the relevant physical regime at all. This can be done using AFM nanoindentation on fresh-frozen thymic cryosections mice. The cortical and medullary regions can be mapped separately using EpCAM/Ly51/UEA-1 immunofluorescence to identify the compartments on the same section. If the cortical stiffness is consistently 3–6 kPa (below K_high), the model's 0–6 kPa scenario is the biologically relevant regime, and the cortex_stiffer advantage in positive selection is a testable prediction. If it is consistently above 10 kPa, the model is currently parameterized in the wrong stiffness regime for the scenarios that show the largest scenario effects.

### Stage-2: Testing Primary Model Predictions
The experiments at this hierarchy are meant to test specific, quantitative predictions that emerge from the model's architecture and that the model makes independently of whether the mechanobiological coupling is working or not.
One of the main experiments of this this stage would study biphasic nature of thymocyte migration speed in relation to substrate stiffness. As the model encodes migration speed as a biphasic Hill function, the parameter of which greatly affects the selection outcomes, its validation is a prerequisite for any mechanobiological interpretation of stiffness-dependent selection. Experiments can be performed with freshly isolated DP thymocytes on polyacrylamide hydrogels of defined stiffness. Tracking of single-cell migration by timelapse phase-contrast microscopy can be done to extract mean migration speed, persistence length, and diffusivity as functions of gel stiffness. The results might show that migrational speed peaks at some intermediate stiffness and declines on both sides, as the biphasic model predicts (the location of the peak provides an empirical K_high). On the other hand, the speed might increase monotonically with stiffness, is stiffness-independent, or is biphasic but with a peak at a very different stiffness than modelled. Any of these would require revising the migration module for fine-tuning before stiffness-dependent selection predictions can be trusted.
Another test that is part of this stage is one which addresses stromal contact dynamics. Rather than tracking "positively selected" versus "neglected" cells as prospectively known categories (which overstates what current live imaging techniques can establish) the tractable prediction is that cells subsequently exhibiting markers of continued engagement (CD69, sustained TCR signaling) will show different distributions of stromal-contact duration and frequency than cells remaining in a resting DP state. This will reframe the test as a correlation between prior behavior and subsequent marker status rather than an implied foreknowledge of fate.

### Stage-3: Validation of Mechanobiological Coupling
This stage focuses on testing the phenomenological variables representing mechanobiological processes and directly target the null result from ==SA-2== to probe whether the model's mechanobiological channels (C, M, gamma, alpha_C_max) represent real biology that might become visible with a slower timescale pathway. As these variables are not molecularly specific (i.e. C is not equal to F-actin levels or any other particular property of cytoskeletal network and M is not equal to the activation state of a specific mechanosensitive pathway) experiments measuring ZAP70 phosphorylation, Ca<sup>2+</sup> flux, and YAP/TAZ translocation across a stiffness range and time-course do not validate C or M directly. However, these experiments can test whether a slower mechanosensitive signaling process exists that the current two-timescale model (τ_C ≈ 20 min, τ_M ≈ 33 min) does not capture. PA gels presenting ligands to CD3 and CD28 can be used to demonstrate mechanosensing by thymocytes, with phospho-specific staining for ZAP70 and Src family kinase proteins suggesting that sensing of substrate rigidity occurs downstream of TCR activation. Different measurements representing different time scales such as ZAP70 phosphorylation (early TCR signal), Ca<sup>2+</sup> flux (immediate downstream), and nuclear YAP/TAZ translocation (slow, hours-timescale mechanotransduction) can be done to get a more solid sense of the time-scale at which the cytoskeletal and mechanosensitive pathways operate. Additionally, this can test whether a slower mechanosensitive signaling process exists that is not captured by the current two-state model, which can either be used to update the current time-scales at which the channels operate or even be represented as a novel channel in mechanobiological coupling.
